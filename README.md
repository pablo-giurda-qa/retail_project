# Retail Project - PostgreSQL

## Descripción
Proyecto práctico de creación y administración de una base de datos relacional para un comercio minorista, utilizando PostgreSQL.

La base de datos `retail_project` contiene tres tablas:

- **clientes:** almacena los datos de los clientes.
- **productos:** registra productos, precios, stock y categorías.
- **ventas:** registra las ventas y relaciona clientes con productos.

## Operaciones realizadas
- Creación de la base de datos y sus tablas.
- Definición de claves primarias y foráneas.
- Aplicación de restricciones.
- Inserción de datos de ejemplo.
- Modificación de tablas con `ALTER TABLE`.
- Actualización de datos con `UPDATE`.
- Eliminación de registros con `DELETE`.
- Uso de transacciones con `BEGIN` y `COMMIT`.

## Cómo ejecutar el proyecto
1. Abrir pgAdmin o DBeaver.
2. Conectarse al servidor PostgreSQL.
3. Ejecutar `CREATE DATABASE retail_project;`.
4. Conectarse a la base de datos creada.
5. Abrir y ejecutar el archivo `retail_project.sql`.
